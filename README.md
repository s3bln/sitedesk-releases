# SiteDesk — releases

Dépôt **public** hébergeant le flux de mises à jour de [SiteDesk](https://applabz.fr),
l'application macOS de gestion clients de Wasabi Web Design.

Le code source reste privé : seuls l'`appcast.xml` (flux Sparkle) et les DMG signés
et notarisés par Apple sont publiés ici.

- Flux Sparkle : `https://raw.githubusercontent.com/s3bln/sitedesk-releases/main/appcast.xml`
- Dernière version : voir [Releases](../../releases)

Les archives sont signées EdDSA (Sparkle) et notarisées par Apple. L'application
vérifie les deux avant d'installer quoi que ce soit.
